# Оформление AmeDE

Планируются темы Amaterasu (по умолчанию, фиолетовая), Sakura (розовая)
и OLED (чёрная). Реализованных тем здесь пока нет.

Следующая итерация определит общие токены: фон, поверхность, текст, акцент,
границы, состояния, типографика, интервалы. Панель, док, уведомления и терминал
должны получать согласованные настройки из одного источника.
Для OLED дополнительно нужны затемнение, скрытие статичных элементов и сон
экрана; одна палитра не является защитой от выгорания.
