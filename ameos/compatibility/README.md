# ame-compat

`ame-compat` — начальный слой совместимости AmeOS для старых приложений.

## Состав

- **C**: стабильный C ABI в `include/ame_compat.h` и переносимая реализация в `c/ame_compat.c`.
- **C++**: header-only RAII/exception адаптер в `cpp/ame_compat.hpp`.
- **Rust**: безопасные обёртки в `src/lib.rs`, используемые новыми компонентами AmeOS.

## Текущий API

Слой предоставляет минимальный ABI-контракт:

- проверка ABI и версии слоя;
- чтение переменных окружения с корректным определением размера буфера;
- запись переменных окружения с контролем `overwrite`;
- единый набор статусов ошибок для C, C++ и Rust.

Это фундамент, а не полная эмуляция конкретной старой ОС. Следующий этап должен добавить отдельные адаптеры файловой системы, оконного API и запуска процессов, не смешивая их с базовым ABI.

## Проверка

Из каталога `ameos/`:

```sh
cargo fmt --all -- --check
cargo test --locked -p ame-compat
```

C++ потребители подключают `include/` и `cpp/`, а линковка выполняется с собранной C-реализацией `ame_compat`.
