# ame-gfx

Программный графический API на Rust для рисования в буфер XRGB8888.
`Canvas` заимствует срез `u32`, проверяет размеры и шаг строки в пикселях
и отсекает прямоугольники и маски по границе поверхности. Маски содержат
8-битное покрытие и подходят для отрисовки глифов.

Непрозрачная заливка, маски и переносимое смешивание реализованы на Rust.
Для полупрозрачных заливок на amd64 ядро на SSE2 смешивает четыре пикселя
за итерацию. Короткие участки и остаток строки обрабатывает Rust. Обе
реализации используют одинаковое целочисленное округление.

Из каталога `ameos`:

```sh
cargo test --locked --release -p ame-gfx
cargo test --locked --release -p ame-gfx -- --ignored --nocapture
```

На тестовой FreeBSD 15.0-RELEASE/amd64 полупрозрачная заливка 1920×1080
заняла 5,74 мс на Rust и 3,21 мс с SSE2. Это замер одной операции API.
