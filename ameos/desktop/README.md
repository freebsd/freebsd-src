# AmeDE

Будущие компоненты: сессия, панель, док, настройки и виджеты.
Кода рабочего окружения в первой итерации нет.

Первый прототип использует готовый композитор и готовый терминал. Обычные
компоненты работают от пользователя; привилегированные операции выносятся
в отдельный ограниченный интерфейс. Установка — пакетами в `/usr/local`.
