# ame-loader

Терминальный прототип загрузчика AmeOS в стиле archinstall.

## Управление

- `↑` / `↓` — перемещение по пунктам;
- `Enter` — выбор пункта;
- `Esc` — возврат назад или выход из загрузчика.

## Архитектура

Загрузчик построен на модульной архитектуре с вложенными экранами:

- **screen.rs** — трейт `Screen` и перечисление `Action` для навигации;
- **menu.rs** — компонент меню с поддержкой навигации клавишами;
- **backend.rs** — абстракция `BootBackend` для операций загрузки;
- **main.rs** — навигационный стек и интеграция с backend.

## Меню

### Главное меню

1. Boot AmeOS — загрузка с профилем по умолчанию
2. Boot profiles — выбор профиля загрузки
3. Boot recovery environment — среда восстановления
4. Hardware diagnostics — диагностика оборудования
5. Power off — завершение работы

### Boot profiles

1. Default — стандартная загрузка
2. Single user mode — однопользовательский режим
3. Safe mode — безопасный режим
4. Back to main menu — возврат в главное меню

### Recovery Environment

1. Mount filesystems — монтирование файловых систем
2. Network configuration — настройка сети
3. Shell — запуск recovery shell
4. Back to main menu — возврат в главное меню

### Hardware Diagnostics

1. Memory test — тест памяти
2. Disk test — тест дисков
3. CPU information — информация о процессоре
4. Back to main menu — возврат в главное меню

## Backend

Текущая реализация использует `StubBackend`, который выводит сообщения о предполагаемых
действиях. Реальная интеграция с загрузчиком FreeBSD и передача управления ядру будет
добавлена отдельным этапом.

Для замены stub-реализации на настоящий backend достаточно создать структуру,
реализующую трейт `BootBackend`, и передать её в `main()`.

## Проверка

Из каталога `ameos/`:

```sh
cargo run -p ame-loader
```

Для выхода из любого меню нажмите `Esc`. Выход из главного меню завершает работу загрузчика.
