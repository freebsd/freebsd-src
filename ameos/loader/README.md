# ame-loader

Терминальный прототип загрузчика AmeOS в стиле archinstall.

## Управление

- `↑` / `↓` — перемещение по пунктам;
- `Enter` — выбор пункта;
- `Esc` — выход из загрузчика.

Сейчас пункты Boot/recovery/diagnostics отображают подтверждение выбора. Реальный
запуск ядра, recovery-среды и диагностики будет подключён отдельным этапом.

Проверка из каталога `ameos/`:

```sh
cargo run -p ame-loader
```
