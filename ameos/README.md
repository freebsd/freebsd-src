# Компоненты AmeOS

Этот каталог содержит собственный слой проекта поверх дерева FreeBSD.

| Путь | Назначение | Состояние |
| --- | --- | --- |
| `base-revision` | Исходный коммит FreeBSD | Зафиксирован |
| `profiles/` | Состав и параметры сборки | `base-amd64` и экспериментальный `compact-amd64` |
| `scripts/` | Создание образов из коммита, native smoke | Полный выпуск ещё не проверен |
| `docs/` | Архитектура, сборка, дорожная карта | Начальная документация |
| `desktop/` | Компоненты и сессия AmeDE | Описаны границы, кода пока нет |
| `themes/` | Общая система оформления | Описаны требования |
| `overlay/` | Дополнительные файлы будущего образа | Пока не применяется |
| `ports/` | Будущие пакеты AmeOS | Рецептов пока нет |
| `tests/` | Проверки скрипта сборки | Без компиляции FreeBSD |

Текущий скрипт не устанавливает AmeDE и не применяет overlay. Он создаёт
базовый образ средствами FreeBSD. Имя AmeOS задаётся в именах выходных файлов;
идентификация установленной системы пока остаётся FreeBSD.

Новые shell-скрипты запускаются через `sh`; исполняемый бит не требуется.
Файлы этого каталога должны сохраняться с LF. Проверки:

```sh
node ameos/tests/build-release.test.mjs
```

Полный маршрут работы описан в [инструкции сборки](docs/build.md).
