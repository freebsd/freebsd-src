# Пакеты AmeOS

Место для будущих рецептов пакетов AmeDE и оформления. Начальный профиль
не использует ports и внешние репозитории.

Перед интеграцией нужно определить версии/ревизию ports, ABI базы, зависимости,
подписи и источник обновлений. Пакеты окружения устанавливаются в `/usr/local`;
пакеты базы и приложения должны иметь явную политику совместимости.
