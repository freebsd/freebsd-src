# Дополнительные файлы системы

Место для будущих конфигураций и ресурсов образа. Начальный профиль ничего
отсюда не копирует. Перед подключением нужны явный список файлов, права,
обработка конфликтов и включение в METALOG/установленные наборы.

Пользовательские настройки следует применять как defaults: обновление
окружения не должно перезаписывать пользовательскую конфигурацию.
